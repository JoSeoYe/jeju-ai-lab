# 제주 관광 AI 실습 (jeju-ai-lab)

제주 관광 데이터를 활용해 AI 실습을 진행하는 저장소입니다.

## 폴더 구조

```
jeju-ai-lab/
├── data/      # 실습 데이터
├── outputs/   # 결과물
├── prompts/   # 내 프롬프트 기록
└── README.md
```

## 각 폴더에 넣는 것

### `data/` — 실습 데이터
AI 실습에 입력으로 사용하는 원본 데이터를 넣습니다.
- 제주 관광지·맛집·숙소 목록 (CSV, Excel 등)
- 관광객 통계, 방문객 수, 날씨 등 공공 데이터
- 리뷰, 안내문 등 분석에 쓸 텍스트 자료

> 원본 파일은 되도록 수정하지 말고, 가공한 데이터는 파일 이름을 구분해 저장하세요. (예: `jeju_tour_raw.csv`, `jeju_tour_clean.csv`)

### `outputs/` — 결과물
AI로 만든 결과물을 저장합니다.
- 여행 일정표, 관광지 추천 목록
- 요약문, 홍보 문구, 블로그 초안
- 분석 결과 표, 차트 이미지, 보고서

> 파일 이름에 날짜를 붙이면 관리하기 쉽습니다. (예: `2026-11-03_3박4일_일정.md`)

### `prompts/` — 내 프롬프트 기록
실습하면서 사용한 프롬프트를 기록합니다.
- AI에게 입력한 프롬프트 원문
- 프롬프트를 수정한 과정과 이유
- 결과가 좋았던 프롬프트, 아쉬웠던 프롬프트에 대한 메모

> 어떤 프롬프트로 어떤 결과물(`outputs/`)이 나왔는지 함께 적어 두면 나중에 비교하기 좋습니다.

## 참고
- 빈 폴더도 Git에 올라가도록 각 폴더에 `.gitkeep` 파일을 넣어 두었습니다. 파일을 추가한 뒤에는 지워도 됩니다.
